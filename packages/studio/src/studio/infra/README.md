# studio/infra — 장비 사이의 공통 실행 코드

`http_store.py`는 중앙 API에 연결하는 파일 저장소 어댑터입니다. 기존 stage_bundle의
로컬 검증·원자 준비를 유지하며 SMB 대신 인증된 HTTP로 파일을 가져옵니다.

`storage.py`는 현장 공유 폴더의 파일을 SHA-256 키로 보관하고 로컬 캐시로 복사합니다.
`agent.py`는 인증된 API 호출과 프로세스 단일 실행 잠금을 제공합니다.
앱을 import하지 않으며 중앙 DB나 RabbitMQ에 직접 연결하지 않습니다.
공유 폴더 경로는 설정으로 주입하고, OS의 SMB 계정 연결은 실행 계정에서 미리 준비합니다.

`runtime_process.py`는 시연용 Shipping 프로세스의 선택적 수명주기 관리자입니다.
Windows 호스트·실행 파일별 잠금, 프로세스 식별, 정지 의도, 제한된 재시작과 마지막 정상 파일 확인을 담당합니다.
호스트 잠금은 PC2 자동 복구 키트와 공유해 서로 다른 관리 모드의 동시 실행도 거부합니다.
Show Agent와 HTTP 키트가 같은 소스를 사용하며, 키트 발급 때 이 모듈을 단일 파일로 복사합니다.
설정과 검증 범위는 [시연 프로세스 안내](../../../../../apps/show_agent/LIFECYCLE.md)를 따릅니다.
