# studio/generation — 소재 생성 (배경 · 에셋 Worker)

현재 LocalShapes가 지원하지 않는 주인공은 오류입니다. 타원 placeholder로 대체하지 않습니다. 실제 AI 공급자 연결·품질 검수 완료를 뜻하지 않습니다.

Head의 지시대로 소재를 만들고 풀에 쌓는 곳입니다.

현재 기본 `LocalImage`와 `LocalShapes`는 흐름 검증용입니다. 함수 호출 성공이나 규칙 검사 통과가 외부 AI 작품의 스타일·구성 품질 승인을 뜻하지 않습니다. 실제 외부 이미지·영상 공급자는 별도 연결이 필요합니다.

- **실행 장비**: 중앙(central). 목표 구조에서는 외부 AI 공급자 어댑터 · 전처리 Worker가 됩니다.
- **가져다 쓰는 것**: [contracts](../../../../contracts/README.md)(필요한 소재 · 의도 모델), [db](../../../../db/README.md)(소재 풀 `asset` 테이블), [verify](../verify/README.md)(입구 검사)

| 파일 | 내용 |
|---|---|
| `assets.py` | 필요한 소재 계산 → 풀에서 고르기(사용자 제작의 '풀에서 고르기'만, 가장 적게 쓴 것) / 새로 생성 → 입구 검사(`verify`) → 풀 저장. 전시 모드는 소재 선택과 상관없이 항상 새로 생성 |
| `images.py` | 이미지 생성 공급자. 기본 `LocalImage`(외부 호출 없는 시험용 PNG). 실제 이미지 API는 같은 `generate`로 붙임 |
| `subjects.py` | 보이지 않는 주인공 데이터: 실루엣 점(형상), 흔적 경로(발자취 · 자취). 실루엣은 사용자 제작에서 테마와 상관없이 풀에서 재사용하고, 전시 모드는 항상 새로 생성 |

예정: 깊이 추정 Worker, 에셋 이미지 · 마스크, 루프 영상 · 소리, 배경 · 에셋 Worker를 각자 큐로 도는 비동기 구조.
