## 충돌과 예시 처리

| 표현 | 적용 판단 |
|---|---|
| 나전칠기 큐브 예시 vs 기하학 금지 | 반복된 EARTH 원칙 우선. 큐브는 기본 제외. 자개색은 자연 표면의 표현 후보. 최신 사용자가 큐브를 지정하면 별도 변형으로 기록 |
| 이끼 돌 방·관객·바닥 반사 vs 인공 구조물 제외 | 문서도 돌 방을 목업 기준으로 명시. 설치 목업과 자연 콘텐츠를 분리 |
| 밝은 복도 vs 어두운 공간 참고 | 실제 조건은 밝은 복도. 참고의 대비·부피·몰입 규모만 취하고 암실로 변경하지 않음 |
| 화면 가득 vs 작은 요소 | 전체 구도와 구성 단위의 차이. 작은 요소가 연속 자연 현상을 이루면 양립. 무작위 과밀도 해법은 아님 |
| 매 동작 AI 이미지 생성 | 사용자 확인으로 반응과 비동기 AI 갱신을 분리. 매 프레임/손짓마다 API 호출하지 않음 |
| 실시간 생성 vs 8시간 루프 | 파일 길이인지 연속 운영인지 미정. 파일 반복을 실시간 생성이라 보고하지 않음 |
| 데모 10종 vs 별첨 9종 | 서로 다른 기획 항목으로 보존. 스킬 변경으로 제작 실행하지 않음 |
| 형성2초 / 소멸5초 이상 | 수치 예시. 원칙은 형성보다 긴 소멸·이탈 후 잔류. 작품별 목표를 기록·고정 후 검증 |
