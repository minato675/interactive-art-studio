# EARTH 소재별 운동 후보

아래는 선택 가능한 창작 제안이며 확정 작품 목록·시뮬레이션·생물학적 정답이 아니다. 7테마를 기계적으로 채우지 말고 현재 기획의 자연 현상과 사용자 요청을 따른다. 공통 구조는 [motion-and-interaction.md](motion-and-interaction.md)의 국소 발생·확산·합류·잔류·소멸이다.

| 자연 현상 | 본체와 깊이 | 입력에서 공유 흐름으로 | 남는 흔적 |
|---|---|---|---|
| 파도·해변 | 두꺼운 파도면과 얇은 수막·포말, 전후 파동층 | 국소 물결이 전달되고 다른 파동과 공동 곡률을 만듦 | 잔물결·포말·압력 방향이 서서히 옅어짐 |
| 이끼·원시림 | 식생의 촘촘한 표면·깊은 층, 가지와 잎의 지지 | 잎과 습윤한 빛의 변화가 주변 층으로 이어짐 | 흔들림·빛의 이동·흩어진 잎이 늦게 안정됨 |
| 낙화·꽃잎 | 접힌 면·투과·가림, 가까운/먼 꽃잎 | 움직임이 국소 기류를 만들고 여러 기류가 공유 하강/휘어짐으로 합류 | 떠난 뒤에도 남은 꽃잎이 느리게 이어져 가라앉음 |
| 꽃·개화 | 중첩 꽃잎과 내부 가림 변화, 줄기의 지지 | 국소 변화가 꽃 군집의 방향·개화 상태에 전달 | 펼침·기울기·주변 꽃잎이 완만하게 복귀 |
| 들판 | 지지된 풀·이삭, 위치별 다른 위상·휘어짐 | 바람이 연속 전달되고 여러 유입이 하나의 바람길을 만듦 | 눕고 되돌아오는 식생의 시간차 |
| 수중·고래 | 유영의 질량·꼬리 추진, 물의 부피로 읽히는 형상 | 주변 물길이 반응하고 고래/물질의 이동과 연결 | 후류·미세 물결이 머물며 감소 |
| 안개·하늘 | 밀도·투과·가림으로 부피, 층별 느린 이류 | 손짓 주변의 갈라짐이 이어지고 다시 합류 | 희미한 통로·밀도 경계가 늦게 닫힘 |

폭발하는 파도·불씨·빠른 광고 컷은 스케일 참고에서 분리한다. 고래가 물을 뚫고 등장하는 예시도 반드시 폭발적 속도를 요구하지 않는다. 생물의 외형을 작품화해도 관절·추진·방향 전환의 연속성은 유지한다.

## 별도로 선택할 소재

나비를 요청하면 몸통·날개의 관절, 날갯짓·굽힘·몸통 운동, 연속 궤적을 확인한다. 접근·회피는 선택 행동이며 나비만 관객을 따라다녀 전체 공유 현상을 대체하지 않게 한다. 복제된 위상·경로, 날개 끝만 흔드는 아이콘 효과를 피한다.

우주·천체·팝아트·기하학 추상은 현재 EARTH 기본 후보가 아니다. 사용자가 명시하면 별도 변형으로 설계하고 현재 전시 적합성을 자동 인정하지 않는다. 원문 풍선 반응은 서서히 부피를 잃는 관계의 예시다. 풍선을 전시 필수 소재로 자동 추가하지 않는다.

## 실제 운동을 볼 때

본체의 위치·방향·변형·주변 흐름이 연결되는가? 눈으로 따라갈 수 있으며 느린 중에도 변화가 읽히는가? 입력의 원인이 확산·합류 후에도 남는가? 정지/이탈 후 흔적이 즉시 사라지지 않는가? 전체 화면 왜곡·카메라 팬만으로 이런 운동을 대신하지 않았는가? 답은 실제 재생·실행 증거와 함께 기록한다.
