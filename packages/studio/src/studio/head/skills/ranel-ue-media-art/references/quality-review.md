# EARTH 제작 단계별 검수

기준 출처는 사용자 제공 `라넬-킨텍스-전시기획초안 (1).pdf`의 1~5쪽이다. 배점과 90점 문턱은 PDF에 있는 수치가 아니라 기존 프로젝트의 내부 후보 채택 기준을 이어받은 **제안 프로파일 `earth-review-v1`**이다. 항목·배점은 [quality-rubric.json](quality-rubric.json)에 고정한다. 결과를 통과시키려고 배점·문턱·이미 기록한 점수를 바꾸지 않는다. 사용자가 기준을 변경하면 새 버전을 만들고 이전 결과를 보존한다.

후속 사용자 확인인 가로 12m·높이 3m의 4:1 화면, 뎁스카메라, 실시간 반응과 비동기 AI 이미지·에셋 갱신 구조를 PDF의 모호한 표기나 예시보다 우선한다.

**라넬 참고영상 자체는 우리 납품 후보가 아니다.** 예시의 큐브·풍선·가상 회랑을 EARTH와 다르다는 이유로 탈락 처리하지 않는다. 표현 지향(질감·부피·규모·국소 변형)과 실제 12m 직선 벽의 납품 조건을 분리한다. 아래 점수는 우리가 새로 제작한 해당 역할의 결과에 적용한다. 최신 사용자가 별도 소재를 명시하면 그 요청을 평가 근거에 기록하고 기본 EARTH와의 차이를 설명한다.

## 증거와 판정

- 각 관찰에 실제 파일·프레임/구간·실행 조건을 연결한다. `observed`(직접 관찰), `measured`(방법을 갖춘 측정), `inferred`(추론), `proposed`(설계)를 구분한다. 기획안이 설명한 레퍼런스를 읽었다는 것과 그 영상의 해당 구간을 직접 보았다는 것은 다르다.
- 검사 상태는 `pass`, `fail`, `unknown`, `not_applicable`로 기록한다. 자료가 없거나 실행하지 않았으면 `unknown`이다. 실패와 미검증을 섞지 않는다. `not_applicable`에는 해당 산출물에서 제외하는 이유를 적는다.
- 관찰과 감점 이유를 먼저 적고 합산한다. 필수 배점 항목 중 증거가 부족하면 총점은 `null`로 두고 확인된 항목 점수만 남긴다. 빈 항목을 만점으로 채우거나 확인한 항목끼리 100점으로 환산하지 않는다.
- 자동 시각 평가는 후보 선택을 돕는 주관적 판단이다. 정지 시안, 모의 입력 프로토타입, 실제 센서 실행, 현장 검증의 판정을 따로 저장한다. 시안 90점으로 시간·인터랙션·현장 완성을 인증하지 않는다.
- 모델의 `candidate_pass`와 아트디렉터의 최종 선택을 구분한다. 사람의 최종 검토가 아직 없으면 `human_review_pending`을 남기고, 이미 허용된 시안 개선·기록 작업은 계속할 수 있다.

## 1. 정지 이미지

실제 원본을 열어 전체 구도와 필요한 세부를 확인한다. 사용자가 확정한 아트월은 **가로 12m·높이 3m, 4:1**이다. 실제 출력 W×H·매핑 확정과 구분하며, 물리 크기만으로 픽셀 해상도를 만들지 않는다. 다른 비율의 콘셉트 탐색은 가능하나 최종 화면 구도 검증을 통과했다고 쓰지 않는다.

검수의 중심은 다음과 같다.

| 항목 | 실제로 볼 것 |
|---|---|
| 자연의 정체성 | 이끼·물·식생·꽃잎 등 EARTH의 현상과 물성이 읽히는가. 모든 테마를 임의의 우주 도형으로 치환하지 않았는가 |
| 화면 충만도·스케일 | 자연 현상이 화면 전반의 주인공인가. 거대한 단일 물체뿐 아니라 작은 요소들의 연결된 밀도·방향·가림으로도 큰 현상을 만들 수 있다. 작은 장식을 구석에 두거나 빈 검정을 주인공으로 삼지 않는다 |
| 깊이·부피 | 앞·중간·뒤의 크기·가림·후퇴·곡률이 읽히는가. 밝기·블러·얕은 텍스처만으로 평면을 감추지 않았는가 |
| 질감·빛 | 물·빛·이끼 등의 물성이 선명하고 두께·표면·투과가 일관적인가. 흰 번짐이 디테일을 지우지 않는가 |
| 화면과 시선 | 중·하단에 주요 경험이 놓이며 가로로 긴 화면에서 흐름이 이어지는가. 중요한 형상이 의도 없이 잘리지 않는가 |
| 파일·시각 결함 | 실제 치수·알파·파일 무결성, 불필요한 글자·인물·로고·전시장 외곽, 합성 경계와 반복 결함을 확인했는가 |

어두운 배경은 깊이와 대비를 만드는 수단이다. 기존의 넓은 검은 여백 규칙을 새 전시의 점수 보너스로 쓰지 않는다. 화면 충만도는 모든 픽셀을 밝히거나 모든 틈을 장식으로 막으라는 뜻도 아니다. 밝은 복도에서의 실제 가독성은 현장 검사 전에는 미검증이다.

기획안의 공통 금지 원칙에 따라 기하학 도형·네온 사인·인공 구조물을 작품의 중심 모티프로 삼지 않는다. 문서 속 큐브·돌 방 예시는 이 원칙과 충돌하는 참고 선택으로 남기며 자동 채택하지 않는다. 전시장 목업을 요청한 경우의 건축·관객은 `reference_mockup`으로 분리하여 판단한다. 발광하는 자연물 자체를 네온 사인으로 오인해 배제하지 않는다.

정지 이미지에서 ‘느려 보이는 구도’를 제안할 수 있지만 느린 운동·잔류 시간·관객 반응을 검증했다고 채점하지 않는다. 깊이맵·패럴랙스가 있더라도 숨은 면·독립 개체·실제 3D·센서 연동을 자동 확보한 것으로 판단하지 않는다.

## 2. 시간과 인터랙션

실제 영상 또는 실행 결과에서 `원인 → 발생 → 확산 → 합류 → 잔류 → 소멸/자율 상태 복귀`를 본다. 이 단계는 별도 100점 프로파일이다. 모의 입력으로 검증하면 그 판정의 범위도 모의 입력이다. 고정 영상으로 시간 품질은 볼 수 있으나 실제 입력과의 인과관계는 증명할 수 없다.

가장 큰 비중은 **생성보다 느린 소멸과 남는 흔적**이다. PDF의 생성 2초·소멸 5초 이상, 퇴장 뒤 5초 잔류는 예시다. 모든 작품의 고정 타이머나 생물학적 법칙으로 바꾸지 않는다. 선택한 현상에서 생성·소멸의 시작과 끝을 같은 관찰 기준으로 정의하고, 입력이 멈추거나 끊겨도 궤적·밀도·방향이 일정 시간 이어지는지 실제 시간축에서 확인한다.

다음 시험을 해당 산출물과 구현 단계에 맞게 실행한다.

| 상황 | 관찰·기록 |
|---|---|
| 무관객 | 자율 현상이 유지되고 단순 대기화면처럼 멎지 않는지 |
| 한 사람의 이동·정지 | 입력 위치 부근에서 시작하여 주변으로 전달되는지; 인식 지연과 예술적 확산 시간을 구분하여 기록 |
| 정지·퇴장 뒤 | 새 자극이 멈춘 뒤 흔적이 남는지; 생성보다 소멸이 느린지; 갑자기 꺼지거나 영구 고착되지 않는지 |
| 여러 사람의 교차·합류 | 독립 효과들이 단순 X자로 지나가거나 사람별 분리된 섬에 머물지 않고 하나의 현상으로 연결되는지 |
| 빠른 손짓·반복 입력 | 즉시 폭발 후 소등, 화면 전체 섬광, 급격한 컷 전환으로 바뀌지 않는지; 과밀 입력에도 완만한 변화가 유지되는지 |
| 입력 상실·복귀 | 유효하지 않은 좌표로 순간이동하거나 오래된 입력을 계속 추격하지 않는지; 잔류와 자율 복귀가 자연스러운지 |

시간 품질은 형태·재질·가림의 연속성, 눈으로 따라갈 수 있는 속도, 느린 변화 안의 긴장으로 평가한다. 단순히 전체 영상을 느리게 재생했다고 통과시키지 않는다. 프레임 샘플만 본 경우 연속 재생·전 구간 검토 상태를 별도로 남긴다.

## 3. 실제 센서·LED·운영

이 항목들은 점수로 상쇄할 수 없는 **해당 단계의 완료 조건**이다. 이미지 시안 검수 때 매번 장시간 운영 시험을 요구하지 않는다.

- **뎁스카메라:** 실제 연결 여부, 장비 좌표→작품 좌표 매핑, 감지 범위·사각·다중 관객·가림·신뢰도·상실/복귀를 실행으로 확인한다. 목표 인원·카메라 모델이 미정이면 그 한계를 기록한다.
- **LED와 관람:** 실제 W×H·크롭·매핑·설치 방향과 중·하단 집중, 중앙/측면·근거리/원거리의 가독성, 밝은 복도 조명에서 검정·질감·하이라이트를 확인한다. 모니터 시연만 있으면 현장 상태는 `unknown`이다.
- **성능:** 실제 장비와 최대 표현 조건에서 FPS·프레임 시간·입력부터 반응까지의 지연을 측정한다. 목표값은 프로젝트에서 정한 값과 비교하며 임의 기준을 확정 요구처럼 만들지 않는다.
- **실시간 반응과 비동기 AI 갱신:** 사용자가 확정한 구조는 실시간 관객 반응과 비동기 AI 이미지·에셋 갱신의 분리다. 매 입력·매 프레임마다 AI 생성을 요구하지 않는다. 반응 경로의 입력→화면 변화와 갱신 경로의 생성 요청→반환→검수→화면 적용을 각각 기록한다. 갱신 대기·실패에도 현재 작품의 반응이 유지되고, 새 결과 적용이 갑작스러운 컷이나 형태 단절을 만들지 않는지 확인한다. 관객 입력 처리와 AI 갱신의 실제 연결 범위를 넘어 ‘매 순간 AI가 새로 그린다’고 표시하지 않는다.
- **8시간 목표:** PDF의 ‘10/30 전후 8시간 루프 콘텐츠 목표’는 운영·콘텐츠 요구로 기록하되, 8시간 길이의 고정 파일인지 연속 운용인지 반복 구성인지 아직 확정하지 않는다. 운영 검증 범위가 정해지면 그 시간·장비·복구 조건으로 검사한다. 짧은 녹화나 이미지 10종으로 8시간/실시간 생성 충족을 대신하지 않는다.

최종 전시 채택은 점수, 해당 단계의 필수 검사, 아트디렉터의 실제 결과 검토를 함께 본다. 다음 수정은 가장 큰 감점 또는 명확한 필수 검사 실패 한 가지를 겨냥하고 부모 결과·관찰·변경점·남은 제한을 보존한다.
