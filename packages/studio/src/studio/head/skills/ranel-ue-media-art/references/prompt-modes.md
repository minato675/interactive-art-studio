# 산출물별 프롬프트

reference_mockup, content_still, production_asset는 기록용 분류이며 생성 도구 전용 파라미터가 아니다. 현재 요청의 종류를 정하고 콘텐츠 시안·설치 목업·실제 런타임 지시를 분리한다. [shared-example-prompts.txt](shared-example-prompts.txt)는 과거 원문 아카이브다.

## 출력 콘텐츠 시안

현재 기본은 EARTH·4:1·화면을 채우는 자연 현상·중하단 시선·선명한 질감·전후 깊이다. 실제 생성 도구가 반환한 크기를 별도로 기록한다. 프롬프트에4:1이라고 쓴 것만으로 실제 비율이4:1이라고 표기하지 않는다. 전시 콘텐츠는 글자·관람객·실제 전시장·LED 하드웨어 없이 작품 픽셀로 만든다.

작성할 항목:
- 자연 현상과 큰 전체 구조, 중·하단의 주목점.
- 구성 단위: 연속 부피인지 작은 단위의 집합인지. 작은 단위가 큰 흐름을 이루는 구체적 방식.
- 전경·중경·후경의 가림·크기·질감 차이.
- 주색·보조색과 국소 어두운 틈, 밝은 환경에서 필요한 형태 대비.
- 정지에 담을 한 순간. 실제 시간 목표는 후속 운동 설계에 분리.
- 요청 비율·실제 출력·reference 역할·유지/수정 영역.

예시(고정 문안 아님):

> 가로12m·세로3m EARTH LED 전시용4:1 와이드 콘텐츠 시안 한 장. 작은 물결 조각과 얇은 수막들이 중하단의 서로 다른 유입에서 합류해 큰 파도면으로 이어진다. 개별 단위는 가까이서 구분되고 멀리서는 화면 전체를 채우는 물의 힘과 부피가 읽힌다. 전경 수막의 두께·굴절과 포말, 중경의 공유 곡률, 깊이 후퇴하는 물결층을 분명하게 만든다. 국소 어두운 틈으로 층을 분리하되 큰 빈 검정이 구도를 지배하지 않는다. 팔레트는 자연스러운 물의 색과 절제된 빛. 느린 흐름의 한 순간으로 보이는 선명한 형상. 폭발·모션블러·기하학 도형·네온 사인·인공 건축·관객·글자 없이 자연 현상만 담는다.

이 이미지로 속도·상호작용을 검증했다고 쓰지 않는다. 새로운 장면에 과거 생성 작품을 자동 참조로 넣지 않는다. 스타일 참고는 실제 파일을 먼저 열고 style_only, 수정은 해당 부모를 edit_target으로 기록한다. 입력 역할과 사용할 조형 원리를 명시한다.

## 설치 목업

요청된 경우에만 만든다. 밝은 복도·12m×3mLED·관객 위치·중하단 시선·설치 높이의 확정/가정을 기록한다. 관람객·바닥 반사는 몰입과 스케일을 설명하는 요소다. AI 목업을 실제 설치사진으로 부르거나 사다리꼴 화면 픽셀을 출력 콘텐츠로 사용하지 않는다. PDF의 어두운 예시와 실제 밝은 환경을 구분한다.

## 제작용 에셋

| 산출물 | 필요한 정보와 검증 |
|---|---|
| 배경/층 이미지 | 역할·가림 순서·여유 영역·실제 크기. 배경 한 장을 전체 인터랙션 구현으로 표시하지 않음 |
| 작은 개별 요소 | 잎·꽃잎·물결 조각의 변형 범위·피벗·기준 크기·방향·필요한 실제 알파 |
| 표면 텍스처 | 표면 좌표·타일링·필요 채널. 시안에 구워진 광원을 PBR 정보로 자동 간주하지 않음 |
| 상대 깊이맵 | 같은 원본과 픽셀 정렬·깊이 방향·정규화·얇은/투명 경계의 한계. 추정 깊이를 미터 단위 실측·완전한3D로 표시하지 않음 |
| 메시/리그 | 실제 파일·축·스케일·피벗·관절·변형·임포트 결과. 이미지 생성만으로 확보됐다고 주장하지 않음 |
| 런타임 제어 | 입력 좌표·유효성, 국소 발생·전파·합류·잔류·소멸, 갱신 전환 |

PNG 확장자만으로 투명 배경을 확인하지 않는다. 깊이 기반 약한 패럴랙스는2.5D시연이며 가려진 표면·개별 잎 운동을 복원한 증거가 아니다. 에셋 제작 방법은 실제 도구 가용성과 사용자 요청을 따른다.

## 기록

이미지 생성에는 imagegen 스킬을 적용한다. 부모·입력 역할·완전한 프롬프트·실제 생성 도구와 크기·검수 근거를 남기고 원본을 보존한다. 영상은 [video-production.md](video-production.md), 비동기 갱신은 [ue-production.md](ue-production.md), 판정은 [quality-review.md](quality-review.md)를 따른다.
