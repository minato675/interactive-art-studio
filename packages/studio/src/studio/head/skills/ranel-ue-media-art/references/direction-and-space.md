# 전시 공간과 레퍼런스 해석

현재 물리 화면은 사용자 확인 **가로12m × 세로3m**, 콘텐츠 구도4:1이며 실제 시연은 직선 벽을 기준으로 한다. 실제 입력 픽셀·프로세서 분할·크롭·설치 높이·관람 거리는 미정이다. 예전6m×6m나21:9를 자동 적용하지 않는다.

라넬의 예시들은 표현 지향의 근거다. 곡면·방·천장·관객 배치를 그대로 복제할 필요 없이 그 안의 질감·부피·스케일·전후 관계를 직선 벽 콘텐츠에 옮긴다. 실제 전달 영상은 [video-reference-analysis.md](video-reference-analysis.md)를 읽는다.

## 밝은 복도와 중하단 시선

가로로 연속된 한 자연 환경을 만들고 반응의 시작·주요 질감·공유 흐름을 중·하단에서 읽히게 한다. 작품의 윗부분은 깊이와 배경으로 연결한다. 화면 가까이 접근한 관객의 가림과 복도 양쪽에서의 비스듬한 관람을 고려한다. 한 중앙 시점만으로 다수 관객의 관람을 보장하지 않는다.

어두운 전시장 참고는 대비·반사·스케일의 예시이며 실제 밝은 복도를 암실로 바꿔 기록할 근거가 아니다. 단일LED에서 천장·바닥·곡면 전체 투영의 물리 몰입을 그대로 재현했다고 주장하지 않는다. 현장 검정·최대 밝기·반사·세부 가독성은 실제 장비에서 확인한다.

## 소재와 공간

| 공간 선택 | EARTH 적용 |
|---|---|
| 자연 환경의 깊이 | 숲·물속·파도·꽃잎 층의 전후 가림과 연속 후퇴 |
| 열린 부피 | 안개·자연광·물의 흐름이 화면 전체에 공간을 만들며 국소 틈 유지 |
| 전경 접근 | 큰 물결·꽃잎이 가까워지되 갑작스러운 팝·충돌 연출을 강제하지 않음 |
| 돌 방·전시장 건축 | 요청된 설치 목업에 한정. 자연 출력 콘텐츠의 기본 구조로 사용하지 않음 |

안개나 초점 흐림만으로 깊이를 만들지 않는다. 앞뒤 크기·가림·음영을 먼저 세운다. 작은 요소는 전경에서 식별되면서 원경의 큰 현상에 합류해야 한다. 형태마다 다른 초점 전략은 가능하나 핵심 질감이 지속적으로 흐려지지 않게 한다.

## 시점과 착시

다중 관객에게는 공유하는 안정된 카메라를 기본으로 한다. 한 사람의 위치에 따라 전체 카메라를 흔드는 것은 별도 연출이다. 일반적인 깊이 단서와 단일 관찰점의 아나모픽 투영을 구분한다. 아나모픽을 요청하면 물리 화면 위치·관찰점·투영 관계를 별도로 정하고 측면 정합성은 실측 전 보장하지 않는다.

목업 렌즈24mm를 엔진 FOV로 그대로 대입하지 않는다. 관람객이 없는 콘텐츠와 관객·반사 바닥이 있는 공간 목업을 분리한다. 자연 수면의 반사와 외부 갤러리 바닥 반사를 혼동하지 않는다.

## 원리를 가져오는 방식

[exhibition-brief.md](exhibition-brief.md)의 내부 기준 → 인터랙션 원형 → 스케일/모티프 → 공간 참고 순으로 필요한 자료를 고른다. 실제 열어본 구간·날짜와 관찰/추론을 기록한다. 정지 프레임만 본 경우 속도·센서 지연·이탈 후 잔류를 측정했다고 쓰지 않는다.

Flow의 국소 입력·공유 흐름을 우리 화면에 적용하되 함께 촬영된 다른 꽃 벽면을 Flow 자체로 혼동하지 않는다. Rain Room의 국소 빈자리, Fog의 밀도 변화, Solid Light의 느린 부피는 참고 원리이며 동일 매체·추적 장치를 쓴다는 뜻이 아니다. 고래·거대 꽃의 규모는 가져와도 기획이 제외한 폭발·빠른 광고 컷은 기본으로 이식하지 않는다.
