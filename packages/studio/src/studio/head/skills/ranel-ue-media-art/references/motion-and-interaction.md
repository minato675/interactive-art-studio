# 국소 입력에서 공유 현상과 잔류까지

기본 반응은 **발생→확산→합류→잔류→소멸/자율 복귀**다. 나비 접근·회피는 특정 소재의 선택 행동이며 전시 전체의 기본 모델이 아니다. 실시간 반응은 AI 생성 응답을 기다리지 않고 유지하며 새 이미지·에셋은 비동기로 검수·적용한다.

## 입력과 좌표

뎁스카메라가 제공하는 실제 데이터부터 확인한다. 센서가 있다는 이유로 손가락·손·골격 추적이 모두 가능하다고 가정하지 않는다. 입력 위치·속도·유효성·신뢰도·시각을 작품 좌표로 변환한다. 카메라 픽셀·깊이 거리·바닥 좌표·LED 픽셀·엔진 월드 좌표를 동일시하지 않는다. 좌표 보정과 유효 영역을 기록한다.

스무딩·작은 떨림의 무시 범위·반응 반경·입력 TTL은 장비와 현상에 맞춘 조정값이다. 인식 지연과 의도적으로 느린 시각 확산을 분리한다. 즉각적인 작은 시작 단서와 느린 성장·전파는 양립한다. 매 프레임 난수·노이즈·상태 재전환으로 느린 흐름을 떨리게 하지 않는다.

## 현상의 상태

| 상태 | 보일 결과 | 구현에서 분리할 것 |
|---|---|---|
| 자율 현상 | 관객이 없어도 살아 있는 물·숲·꽃잎·안개 | 기본 장과 관객 주입 에너지 |
| 국소 발생 | 움직인 위치 부근에서 변화의 씨앗이 읽힘 | 입력 인식 시점과 가시적 형성 시점 |
| 확산 | 방향·궤적·밀도 변화가 주변과 화면 먼 곳으로 이어짐 | 전달 속도·반경·감쇠와 전체 카메라 움직임 |
| 합류 | 여러 흐름이 만나 공동 방향·곡률·밀도를 만듦 | 단순 X교차·알파 중첩과 실제 공유 상태 |
| 잔류 | 움직임이 멈추거나 사람이 떠나도 이전 궤적·방향이 남음 | 새 입력의 중단과 기존 장의 수명 |
| 소멸·복귀 | 형성보다 오래 걸려 흔적이 약해지고 자율 상태에 합류 | 순간 초기화와 완만한 감소 |

전체 화면은 결국 영향을 받더라도 처음부터 모든 픽셀이 동시에 바뀌지 않게 한다. 여러 사람의 효과가 각각 분리된 섬처럼 남으면 공유 현상을 설계한다. 합류 뒤 일정 구간에서 함께 휘거나 이어지는 실제 시간 경과를 확인한다.

소멸시간은 형성시간보다 길게 설계한다. 기획안의 형성2초·소멸5초 이상은 시작 예시이지 고정 타이머가 아니다. 작품마다 형성 시작/완료, 입력 종료, 잔류 종료, 자율 복귀를 정의하고 시간 목표·실측을 나눈다. 시각적 흔적과 디스플레이 모션블러를 혼동하지 않는다.

## 구현 후보와 안정성

유체/방향장, 수명과 관성을 가진 입자, 변형 가능한 표면, 층별 밀도·가림으로 구현할 수 있다. 이는 설계 후보이며 특정 엔진 노드나 물리 시뮬레이션 완료를 뜻하지 않는다. 작은 요소는 공통 장의 방향을 따르면서 크기·위상·층·가림이 달라야 한다. 거대한 하나의 평면을 왜곡하는 것만으로 독립 요소의 운동을 완료 처리하지 않는다.

다중 입력은 공동 장으로 합성하되 에너지 상한·정규화 등으로 과포화·충돌 진동을 제어한다. 개별 입력의 위치 대응은 유지한다. 관객 수 증가가 전체 화면 섬광이나 무조건 빠른 운동으로 변하지 않게 한다.

입력 상실 시 유효하지 않은 좌표를0,0에 주입하거나 오래된 입력을 계속 추격하지 않는다. 새 주입을 멈추고 기존 흐름을 감쇠시킨다. 복귀 시 이전/새 좌표를 안전하게 연결한다. 추적 ID가 바뀐 것을 사람의 순간이동으로 표현하지 않는다.

다중 관객에게는 공유하는 안정된 카메라를 기본으로 하고 반응은 작품 요소에서 일으킨다. 한 사람의 좌우 이동에 전체 카메라를 흔들거나 개인별 완전한 아나모픽을 보장하지 않는다.

## 검증

무관객, 한 사람 이동·정지·퇴장, 여러 입력의 교차·합류, 빠른 반복 입력, 상실·복귀를 실행한다. 마우스·모의 좌표는 먼저 사용할 수 있으나 실제 센서 연결과 구분한다. 시간·입력 동기 기록이 없는 영상에서 센서 지연을 측정했다고 쓰지 않는다.

시간·인터랙션 판정은 [quality-review.md](quality-review.md)를 적용한다. 정지 이미지에서는 위 행동을 설계만 할 수 있다. 실제 생성된 영상·런타임·실센서·현장 LED를 각각 기록한다.
