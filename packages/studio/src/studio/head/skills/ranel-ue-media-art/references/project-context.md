## 이전 조건의 범위

- 6m×6m·1:1 전시 정보는 이번 12m×3m 확인으로 대체되었다. 21:9는 과거 이미지 시리즈 요청이며 현재 기본값이 아니다.
- 7개 테마 균등 생산과 Flow 고정 점수표는 이전 자동 제작 규칙이다. 현재 확정 작품 개수나 전체 평가로 쓰지 않는다. 자연 계열은 후보로 남기고 우주·팝아트는 명시적 별도 요청에 사용한다.
- 넓은 검은 여백·거대 추상·네 화가 동시 융합·30~60초 영상 고정값을 현재 기본값에서 제외한다.
- 작은 요소로도 구현해 달라는 사용자 방향은 유지한다. 작은 단위가 전체 자연 현상을 만들며 작은 장식을 드문드문 배치하라는 뜻은 아니다.
- 자동 제작 5는 사용자가 중단한 이력이 있다. 기획서 수신·스킬 수정은 재개 지시가 아니다. 기존 수동·자동 원본과 점수를 보존한다.

## 자료 상태

출처와 충돌은 [exhibition-brief.md](exhibition-brief.md)에 있다. PDF 5쪽은 모두 텍스트다. 별첨 방향 이미지 9종과 제작 중 영상은 PDF에는 포함되어 있지 않다. 이후 사용자가 라넬 제공 영상 시안 9개를 별도로 전달했고 실제 파일·표본 프레임을 검토했다. [video-reference-analysis.md](video-reference-analysis.md)와 [company-video-reference-index.json](company-video-reference-index.json)을 사용한다. PDF의 특정 별첨·낙화 작품명과 파일별 대응은 별도로 확인되지 않았다. 데모 10종 일정과 별첨 9종을 같은 목록으로 추정하지 않는다.

[company-reference-index.json](company-reference-index.json)은 2026-10-14의 **과거 인덱스**다. 미수신 플래그를 현재 상태로 읽지 않는다. [shared-example-prompts.txt](shared-example-prompts.txt)는 보존한 원문 예시이며 현재 생성 지시가 아니다.

2026-10-18 조사 기록은 Rain Room·Fog·Solid Light·Waterlicht·Le Space의 문서/선택 구간 확인 이력이다. 상세 파일을 별도 전달받을 때의 재배치 위치는 저장소 루트 기준 `runtime/references/evidence/ranel-interaction-direction-20261018/reference-evidence.json`이며 이 배포본에는 포함하지 않는다. 과거 확인 이력을 현재 파일 보유나 새 관찰의 근거로 쓰지 않는다.

참고 이미지·영상·PDF 원본과 상세 관찰 파일은 배포 대상이 아니다. 인덱스의 `runtime/references/` 경로는 별도 자료 수신 후 사용할 저장소 기준 위치다. 실제 자료가 없으면 동봉된 요약의 관찰 범위만 사용하고, 새로 검토했다고 기록하지 않는다.

## 미정이어도 진행 가능한 작업

4:1 구도, 자연 현상의 구성 단위, 입력→확산→합류→잔류 프로토타입은 진행 가능하다. 장비 연결 단계에서 좌표·유효 범위·손 추적 지원을, 납품 단계에서 출력 픽셀·성능 목표·운영 정의를 확인한다. 중간 시안을 최종 납품 규격이나 현장 승인으로 표현하지 않는다.
