# Head 시나리오 감독

Head는 실제 지원되는 UE 템플릿을 먼저 확인하고 배경을 지시한다. 반환된 배경 원본을 이미지 입력으로 본 뒤, 생성할 원본 에셋과 그것을 재사용하는 장면 인스턴스를 구분해 계획한다. 각 인스턴스의 위치·크기·상호작용 대상 여부를 정하고 효과·입자·시간 전개의 목표와 구현 범위를 함께 남긴다.

## 스킬과 서버 연결

`packages/studio/src/studio/head/skills/ranel-ue-media-art`는 배포 패키지에 포함되는 라넬 스킬이다. `references/scenario-director.md`는 전체 감독 지침이고 `references/head-director-prompt.md`는 API의 background/assets/review 판단에 실제로 주입하는 독립적인 실행 지침이다. API 모델은 로컬 Codex 스킬을 자동 검색하지 않으므로 `director.py`가 이 파일을 읽는다. 참조 영상의 Windows 경로는 출처 이력이며 EC2에서 다시 보았다는 근거가 아니다.

새 흐름의 payload._director에 지침 버전과 SHA-256을 고정한다. 단계 사이에 지침이 바뀌면 새 버전으로 조용히 진행하지 않고 보류한다. 기존 `_director` 없는 흐름은 reason/assets만 있는 이전 계약과 지시를 유지한다. 배포 지침이 누락되면 구체적인 오류로 접수·진행을 막고, 검수 모델이 응답한 뒤 저장·게시하기 직전에도 고정 해시를 다시 확인한다. 판단 결과에는 사용한 지침과 배경 해시를 기록하고 에셋 계획의 `director`를 함께 보존한다. 게시·재작업 횟수·실행기 인증 정책은 기존 [Head 자동 사이클](HEAD_AUTOMATION.md)을 따른다.

## 실제 순서와 시나리오 내용

1. 요청 Spec의 반응·매질과 카탈로그, 온라인 제작 노드의 지문으로 템플릿을 선택한다. Head가 이름만 정해 미지원 템플릿을 실행하지 않는다.
2. 배경의 역할(display/canvas/style_reference), 조명·원근·시선·에셋 통로를 정하고 배경 제작 지시를 남긴다. 배경에 독립적으로 움직일 객체를 구워 넣지 않는다.
3. 실제 배경 원본의 해시·크기를 검사해 모델에 전달한다. 색·빛·원근·이미 차지한 영역·사용 가능한 영역을 관찰한 뒤 에셋을 정한다.
4. `assets`는 유료로 생성할 원본 종류다. `director.instances`는 원본을 재사용할 최종 배치다. 같은 원본을 여러 인스턴스에서 참조하면 추가 생성 없이 다른 위치·크기로 쓴다.
5. 인스턴스별 행동을 현재 선택에 허용된 값 중에서 정한다. `[]`는 정적 객체다. 필요한 follow/glow 대상은 최소 하나 남기며 전체 객체에 같은 행동을 자동 복사하지 않는다.
6. 인터랙션·에셋 효과·입자·시간 단계를 정의한다. 실제 템플릿에서 제어되는 내용과 `design_only` 제안을 구분한다. 조건·대상·형성·잔류·복귀와 검수 기준을 명시한다.
7. 서버가 참조·개수·행동·템플릿을 검사하고 기존 assets.json v1로 변환한다. 생성된 파일은 한 번만 전달하고 복제 인스턴스는 같은 파일을 참조한다.
8. 검수 Head는 감독 명세와 실제 UE 보고서·캡처를 함께 비교한다. 설계한 효과가 실제 적용됐다는 증거가 없으면 구현 완료로 채점하지 않는다.

## 현재 실행 범위

원본 종류와 최종 Sprite 객체는 각각 최대 12개이며 모든 생성 원본은 배치에 사용한다. 총 인스턴스 수는 원본 수와 다를 수 있다. 위치는 왼쪽 위 (0,0), 오른쪽 아래 (1,1)의 정규화 좌표이고 크기는 화면 너비 비율이다. 현재 자동 조립이 적용하는 변형은 위치와 크기다. 회전·색 변형·독립 깊이·메시 변형 등은 기존 계약에 없는 값을 몰래 넣지 않고 별도 제안으로 남긴다.

GPU 입자는 전역 입자장이다. 개별 에셋에 붙이는 방출기는 지원하지 않으므로 template_driven 입자의 target_ids는 빈 배열이어야 한다. 수·반경·복귀 등은 기존 Spec과 템플릿 슬롯의 매핑을 따른다. 감독 명세에 적은 임의의 방출률·수명·힘·입자 종류가 자동으로 Niagara에 연결되는 것은 아니다. 원본 Sprite 12개 제한과 입자 수는 다른 값이다.

현 Head가 확인하는 템플릿은 gpu_particles/image_stir/fluid/paint/deformation이다. fluid/paint/deformation의 far 배경은 가려지는 style_reference다. 실제 배경이 화면에 보여야 하는 요청에서 이를 표시용 배경이라 설명하지 않는다. 미지원 반응·규칙 조합과 오래된 제작 노드 지문은 기존 preflight가 생성 전에 거부한다.

현재 전시 목표는 12m × 3m 직선 벽의 4:1이다. 현 엔진의 제작 권장 배경 1920×1080과 실제 고정 무대·송출 매핑은 별개다. 스킬을 배포한 것만으로 4:1 현장 출력을 완료했다고 기록하지 않는다. 자연 현상의 국소 발생·합류·잔류는 연출 목표이며 현재 템플릿이 증명하지 못한 항목은 설계/미검증으로 남긴다.

## 검증

계약·복제 재사용·대상 선택·지원 범위·원본 의존성·중복 방지와 기존 흐름 호환성을 자동 테스트한다. 스킬 파일이 배포 이미지에 포함되고 실제 API 지시에 들어가는지도 확인한다. 합성 모델을 쓰는 테스트는 GMS의 실제 창작 품질·UE 화면·현장 센서 반응을 증명하지 않는다.
