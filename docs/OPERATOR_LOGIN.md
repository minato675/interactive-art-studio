# 운영 서버 통합과 계정 로그인

2026-10-23 사용자 요청으로 운영 접속은 `https://k15a504.p.ssafy.io`(443) 한 곳으로 통합한다.
배포 기준 브랜치는 `develop`이며 `main`은 이번 변경에서 수정하지 않는다.
8444 테스트 환경은 종료하고 DB·파일·인증 설정은 복구용으로 보존한다. 볼륨을 삭제하지 않는다.

HTTPS 443은 IP 제한 없이 접속하고 운영 기능은 계정 로그인으로 인증한다.
호스트 설정은 `sudo python3 infra/configure_ec2_https.py --public --port 443 --persist`로 적용한다.
공개 모드는 443만 허용하며 SSH·DB·작업 큐 규칙과 포트 바인딩을 변경하지 않는다.
공개 CA가 포함된 최신 PySide를 배포하고 TLS 검증을 유지한다. AWS 보안 그룹은 별도로 대조한다.

## 팀원의 실행 순서

GitLab에서 소스를 받은 Windows PC는 루트의 `Start-Operator.cmd`를 실행한다.
uv가 필요하며 첫 실행은 잠금 파일 기준으로 PySide6 포함 패키지를 설치한다.
uv가 없다면 [공식 설치 안내](https://docs.astral.sh/uv/getting-started/installation/)대로 설치하고 터미널을 다시 연다.
MR 검토 중에는 `S15P31A504-226-single-production-login` 브랜치를 받는다.
병합 후에는 `develop`을 받으면 된다. ZIP 다운로드도 압축을 푼 루트에서 같은 실행 파일을 쓴다.
Windows 외 환경은 저장소 루트에서 `uv sync --locked --all-packages` 후
`uv run --locked --all-packages a504-operator`로 실행한다.
앱에서 관리자가 발급한 ID·비밀번호를 입력한다. 비밀번호와 세션은 파일에 저장하지 않는다.
공개 CA 인증서는 앱 리소스로 제공하며 OS 인증서 설치나 개인별 토큰 파일을 요구하지 않는다.
TLS 호스트 이름 검증은 유지하고 서버 개인키·운영자 토큰은 Git에 넣지 않는다.

## 계정 관리

공개 회원가입은 제공하지 않는다. 최초 관리자 계정은 EC2에서
`docker exec -it ranel-central-1 python -m central.accounts create <ID> --admin`으로 만든다.
비밀번호는 명령행 인자 대신 숨김 입력으로 두 번 받는다.
로그인한 관리자는 앱의 계정 관리에서 새 ID·비밀번호·관리자 권한을 지정한다.
ID는 영문·숫자·`_`·`.`·`-` 3~64자이며 대소문자를 구분하지 않는다. 비밀번호는 12~128자이다.
비밀번호 재설정·비활성화 시 기존 로그인 세션을 폐기한다.
로그아웃 또는 세션 만료 시 다시 로그인해야 한다.

## 인증 경계

비밀번호는 salt를 포함한 PBKDF2-SHA256 해시로 저장한다. 원문 비밀번호는 저장하지 않는다.
세션은 임의 토큰을 발급하되 DB에는 SHA256 해시와 만료 시간만 보관한다.
로그인 실패 제한은 DB에 보관해 프로세스 재시작으로 초기화하지 않는다.
계정 인증은 기존 운영 API·Head API에 적용하고 Agent 전용 토큰과 분리한다.
기존 운영자 토큰은 서버 관리·호환 도구용으로 유지하며 로그인 응답으로 전달하지 않는다.

## 배포와 검증

Draft MR의 코드와 실제 서버 적용 결과는 구분해 기록한다. MR을 자동 병합하지 않는다.
운영의 수동 수정이 develop에 포함되어 있는지 확인한 후 교체하며 진행 중 작업이 있으면 교체하지 않는다.
운영 DB·파일·CA·노드 토큰을 보존하고 백업한다. HTTPS·인증·비동기 진단을 확인한다.
계정 로그인 검증은 실제 이미지 생성 비용이나 UE 현장 적용을 발생시키지 않는다.
로그인 성공이 기존 작품 제작 버튼을 Head API로 전환하는 것은 아니다. 기존 제작·감독 호출 경로는 유지한다.

## 기존 운영 수정 보존

운영에만 있던 시연 대시보드·게시/재생 API·중앙 시연 구성과 Head 대기시간 600초 수정을 이번 Draft에 동기화한다. 기존 운영 release `head-timeout600-20261023-9cdd314fe8e9`의 실제 소스와 develop a9ad06e를 비교해 반영하며 다른 작업 디렉터리는 변경하지 않는다. 기존 검수·승인 조건을 완화하지 않는다.

최초 관리자는 서버 소유자 PC에서 `uv run --all-packages python -m operator_app.bootstrap --env <비공개 운영 env 경로>`로 계정 관리 창을 열어 ID·비밀번호를 직접 지정할 수도 있다. 이 도구는 관리자 토큰이 있는 소유자만 사용하며 팀원에게 env를 전달하지 않는다.
