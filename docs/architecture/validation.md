# 아키텍처 검증 기록

작성일: 2026-10-19 · 문서 기준: 분산형 설계 1.0 / 구성도 v4

## 검사 범위

GitLab `develop`의 `ccd14e9e08cfe5088fef226f5bbb574639b6136a`에서 분기해 문서·구성도만 추가했다. 원래 작업 폴더의 수정 중인 Git·Jira 규칙 파일은 포함하지 않았다. 설치된 개발 의존성은 기존 `uv.lock`을 따랐으며 실행 코드와 의존성 선언을 변경하지 않았다.

## 문서와 도면

| 검사 | 결과 |
|---|---|
| Markdown의 로컬 링크 | 이 문서 묶음의 상대 경로가 모두 존재함 |
| 개인 PC 경로 | 게시 문서에서 제거하고 상대 경로 또는 확인 당시 GitHub 커밋 링크로 변환 |
| UTF-8·코드 블록·JSON 예제 | 깨진 문자와 코드 블록 짝을 검사하고 JSON 예제를 파싱 |
| 이미지·원본 복사 | PNG·SVG·draw.io가 최종 로컬 산출물과 바이트 단위로 동일함 |
| 기존 도면 보존 | 기존 4개 페이지 XML이 원본과 동일함; 새 페이지를 포함해 총 5개 |
| 최신 페이지 | `분산형 설계 · 도형 중심`; 개별 편집 가능한 도형 113개, 연결선 28개 |
| 도면 XML | 셀 ID 중복 없음, 연결선·부모 셀 참조 유효 |
| 미리보기 | PNG 2395 × 1401; SVG XML 파싱 정상; PNG를 열어 글꼴·화살표·범례·전체 배치를 재확인 |

원본 작성 시에는 draw.io 전체 화면과 내보낸 PNG에서 한글·굵은 글꼴·화살표·5개 페이지를 확인하고, 무관한 텍스트와 연결선의 교차 및 접점이 아닌 선 교차를 검사했다. 이번 게시 준비에서는 도면을 다시 그리지 않고 원본을 그대로 복사했다. 외부 링크의 접근 권한이나 서비스 가용성을 보증하는 검사는 아니다.

## 저장소 필수 검사

검사 명령은 [AGENTS.md](../../AGENTS.md)의 완료 전 확인 규칙을 따랐다. Windows · Python 3.13.15 환경에서 실행했다.

| 검사 | 결과 |
|---|---|
| 기존 lockfile로 의존성 동기화 | 성공; lockfile 변경 없음 |
| pytest | **45 passed**, warning 1개 |
| Ruff | **All checks passed!** |

경고는 FastAPI TestClient가 사용하는 Starlette의 `httpx` 지원 중단 예정 안내다. 문서 변경 전 기존 의존성 조합에서 발생했으며 이번 작업에서는 코드·의존성을 바꾸지 않았다. `controller/`를 사용하는 코드를 변경하지 않아 별도 controller 테스트 대상은 아니다.

위 테스트는 저장소의 기존 기능에 대한 검사다. 새 분산 목표 구조 전체의 구현·성능 검증으로 해석하지 않는다.

## 아직 검증하지 않은 항목

- 제안한 PostgreSQL DDL의 실제 적용, 동시 작업 임대·소유권 토큰·재시도 통합 시험
- RabbitMQ·Celery·Windows Agent·독립 시연 장비를 연결한 전체 실행
- UE 목표 버전과 플러그인·콘텐츠 호환성, 실제 장비 성능·무중단 교체
- 공급자 API의 실제 이미지·영상 생성 및 자동화 권한
- Qt 설치본의 라이선스 고지·대응 소스·호환 수정 라이브러리 교체 시험
- 저장소 GPL 계열 제한과 선택한 LGPL 등 구성의 적용 범위·예외 정합성

구현 순서와 완료 조건은 [설계 본문](./distributed-system-design.md), 실제 배포 준비는 [LGPL 체크리스트](./pyside6-distribution-checklist.md)를 따른다.
