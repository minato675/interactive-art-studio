# 최근 아카이브 28개와 PC2 선택 재생

PySide의 `시연 관리` → `로컬 아카이브`에서 원본 보관함의 28개 실행 작품을 조회하고 선택 재생·정지를 요청한다.
이 목록은 `earth-native-20261025-v1`의 고정된 실행 카탈로그이며, 기존 공용 런타임의
`시연 관리` → `공용 런타임` 목록·검수 기록과 구분한다. 반려본 1건과 이후 추가된 다른 수정본을 임의로 포함하지 않는다.

## PC2 준비 조건

서버 등록·목록 조회·재생 요청 저장에는 PC2 하드웨어 정보가 필요하지 않다. 실제 재생에는 해당 작품의
네이티브 UE 실행본·플러그인·리소스와 Agent가 PC2에 설치되어야 한다. 패키지에 실행본이 포함되어 있으므로
재생만 할 때 UE 에디터를 별도로 설치하는 것은 필수 조건이 아니다. Windows·그래픽 API/드라이버 호환은 확인한다.
GPU·VRAM·CPU·RAM·실제 출력 픽셀·목표 FPS는 현장 성능 검증에 필요하며 실측 전 최소 사양을 인증하지 않는다.
뎁스카메라 모델·드라이버·TD/입력 브리지·좌표 매핑은 센서 반응 검증에 필요하다.
현재 원클릭 키트의 기본 카메라 입력은 최대 두 손 인식이며 전신·뎁스 인식의 완료 근거가 아니다.

## 운영자 사용 순서

GitLab 소스의 `Start-Operator.cmd`로 실행해 기존 계정으로 로그인한다. `시연 관리` → `로컬 아카이브`에서
작품을 선택하고 재생 시간·반복을 정한 뒤 `선택 작품 재생 요청`을 누른다. 기존 공용 작품은 같은 탭의
`공용 런타임`에서 관리한다. PC2에 별도로 전달한 전용 설치 ZIP은 그 PC에서 한 번 설치한다.
설치 ZIP에는 기기 등록키가 있어 공개 저장소·공유 웹사이트에 올리지 않는다.
PC2 미접속 때는 요청만 보존하고 실제 실행 보고가 올 때까지 확인 대기로 표시한다.

## 연결

계정 로그인한 PySide → 중앙 `/infra/native-artworks` → Docker 내부 `earth-pc2-queue:8014`
→ PC2 원클릭 설치기에 포함된 native Agent의 `/plan` 동기화 → 설치된 UE 실행기.
중앙이 보유한 운영 키는 내부 요청에만 사용하고 앱·설치기에 전달하지 않는다.
Agent의 등록·다운로드·보고 토큰은 기존 별도 권한을 유지한다.
게이트웨이는 `/infra/earth-pc2/*`의 기기용 경로만 전달하며 내부 `/operator/*`는 공개하지 않는다.

`GET /infra/native-artworks`는 목록·요청 revision·실제 기기 보고를 반환한다.
`POST /infra/native-artworks/play`는 선택 ID, expected_revision, request_id, 공통 재생 시간,
반복 여부를 받는다. `POST /infra/native-artworks/stop`은 같은 revision/멱등 키로 정지를 요청한다.
ID를 실행 인자나 파일 경로로 직접 해석하지 않고 설치 카탈로그에 있는 ID만 허용한다.
중복 요청은 같은 결과를 반환하고 오래된 revision은 409로 거부한다.
새 선택은 Agent가 동기화한 뒤 기존 자식 실행기를 정리하고 새 작품을 실행한다.

## 상태의 의미

- 요청 저장: EC2에 재생 의도만 저장됨. PC2 미접속이어도 저장할 수 있다.
- PC2 연결: 실제 설치기 계정에 묶인 기기의 최신 보고가 있음. 로컬 시험 계정은 제외한다.
- PC2 실행 보고: 최신 queue revision, 기기 ID, 세션, PID, 작품 ID, ready가 모두 일치함.
- 실제 센서·LED·장시간 운영 검증: 별도 현장 확인이며 실행 보고만으로 통과하지 않는다.

PC2에는 원클릭 설치가 한 번 필요하다. 설치기는 UE 실행기·Python·손 입력 지원 파일을
해시 검사 후 준비한다. 설치 전에는 PySide에서 `PC2 미연결 · 요청 대기`로 표시한다.
과거 설치 패키지·원본을 덮어쓰지 않고 새 버전 패키지를 발급한다. 서버와 설치기가 같은
고정 release manifest를 쓰는지 확인하며 설치 키는 공개 저장소에 넣지 않는다.

## 운영·복구

native 서비스 데이터는 `/opt/ranel-earth-pc2/data`에 보존한다. 새 서버 코드는
`infra/native_pc2/server.py`, 설치 Agent는 `infra/native_pc2/agent.py`에 추적한다.
현재 데이터·기기 등록·기존 공용 재생 목록을 초기화하지 않는다. 원본 생성 자동화는 재개하지 않는다.
서버·로컬 모의 검사는 실제 PC2 설치 완료로 기록하지 않는다.
